התחברות ל-Google / יצירת מפתח

מסלול אינו מבקש את סיסמת Google. בוחרים חשבון באתר הרשמי של Google ויוצרים בו מפתח API אישי.
  1. בחירת חשבון: פתח את בחירת החשבון של Google. ניתן לבחור חשבון אחר או להוסיף חשבון חדש.
  2. יצירת מפתח: ב־Google AI Studio בחר Create API key ואת פרויקט Google הרצוי.
  3. חזרה למסלול: העתק את המפתח, חזור לאפליקציה והדבק אותו בשדה שלמטה.
